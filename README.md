# Mario Kart Terminal Edition 🏎️💨

Um simulador de corridas inspirado em **Mario Kart**, desenvolvido em **Node.js** e executado diretamente no **terminal**.  
O jogador escolhe um personagem e participa de corridas cheias de itens clássicos, como cascas de banana, carapaças e cogumelos.  
Toda a lógica do jogo acontece no backend, com interações feitas pelo console.

---

## 🚀 Funcionalidades
- Seleção de personagens clássicos (Mario, Luigi, Peach, Yoshi).
- Corrida simulada em turnos.
- Itens que afetam os competidores (casca de banana, carapaça verde, cogumelo).
- Ranking final com a colocação de cada jogador.
- Execução 100% no terminal.

---

## 🛠️ Tecnologias utilizadas
- **Node.js**
- **readline-sync** (para entrada de dados no terminal)

---

## ▶️ Como executar
1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/mario-kart-terminal.git
   cd mario-kart-terminal

1. Instale dependências:
   npm install
2. Execute:
   npm start
